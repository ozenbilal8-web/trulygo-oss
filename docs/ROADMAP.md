# Roadmap

These are planned improvements, not completed features or adoption claims.

1. Expand isolated database and browser coverage across link approval,
   redirect invariants, access controls, uploads, and surveys.
2. Improve the English interface and operator configuration while preserving
   the existing Turkish experience.
3. Document supported deployment upgrades and recovery procedures from
   reproducible test environments.
4. Validate optional email and automatic approval integrations in controlled
   environments; publish the exact tested scope and known limitations.
5. Improve accessibility and documentation based on actual user feedback.
6. Establish a maintenance record through issue triage, reviewed fixes,
   dependency updates, and release notes.

Requests and contributions should describe a concrete need. Priorities will
follow reproducible issues, maintenance needs, and feedback from actual usage.
